## Dependencies and constraints

Начать по контракту со stub и официальным template, не ждать готового ядра.
После передачи интегрированного commit проверить его в согласованной рабочей
копии, не подменять agent.py на своей ветке и не переписывать scorer.
Без запросов платного API и без новых зависимостей до согласования с Нурсултаном.
Окончательный submission.csv генерирует Нурсултан; Ерлан сверяет результат в
отдельной локальной копии, чтобы не перезаписать общий артефакт.
