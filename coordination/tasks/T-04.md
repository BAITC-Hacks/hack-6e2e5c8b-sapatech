## Validation / handoff

- **Files changed:** `strategy/__init__.py`, `strategy/core.py`,
  `strategy/README.md`, `strategy/tests/test_core.py`,
  `strategy/tests/official_smoke.py`, `coordination/tasks/T-04.md`.
- **Implementation:** current tariff × ARPU candidates; robust historical priors;
  precision-weighted public pilots; repeated confirmation after initial exploration;
  deterministic greedy marginal portfolio with channel prices, ID order, caps,
  final-campaign overlap and estimated pilot coverage. All assumptions are in
  `strategy/README.md`. Only standard library, pandas and numpy are used.
- **Unit validation:** `python -m unittest discover -s strategy/tests -v` —
  14 passed. Includes zero/invalid historical denominators, empty history,
  missing segments, input immutability, changed decisions under changed pilot
  evidence, actual sample sizes, no double channel multiplier, final resource
  reserve, paid channels, overlap, negative fallback and sorted-ID cap behavior.
- **Official integration:** from a local extracted official participant package,
  `PYTHONPATH=/path/to/repository python /path/to/repository/strategy/tests/official_smoke.py --runs 10`.
  Calls unmodified `local_eval.evaluate_agent` through a test-only adapter;
  validates raw final output before sanitation, budget/contact limits, pilots,
  runtime and repeated-seed equality of campaigns and public observations.
- **Final ten-seed results (0–9):** 9/10 positive; median net gain 575,915.02;
  minimum -282,662.44 (seed 2); maximum 943,807.80. 20 pilots/run, 4–10 final
  campaigns, contacts <=15,000 and cost <=100,000 in every run. Strategy runtime
  1.51–1.83 seconds/run in this local environment. Repeat of seed 9 matched.
- **Submission seed smoke (42):** net gain 327,917.04; 15,000 contacts;
  cost 99,998; 20 pilots; 10 final campaigns; runtime 1.75 seconds. Repeated
  decisions and public observations matched. This is not submission.csv validation.
- **Environment:** Python 3.9, pandas 2.3.3, numpy 2.0.2 in a temporary venv;
  organizer data extracted outside the repository. No datasets or dependencies
  added to the repository. Initial exploratory version was less stable; numbers
  above refer to the version with confirmation and 200-contact pilot requests.
- **Commit:** `feat(strategy): implement pilot-aware campaign core [T-04]`;
  this task card is included in that commit. The operator explicitly authorized
  commit and push of `feat/T-04-bauyrzhan-strategy`. Git author verified as
  Bauyrzhan Myrzagaliyev. No merge/rebase/reset or changes to main.
- **Limitations:** hidden judging unavailable; history does not identify causal
  conversion. Cross-channel extrapolation and pilot overlap are approximations.
  One negative seed remains; positive net gain is not guaranteed. Production
  `Agent.act`, bounded pilot error recovery and submission generation are T-03.
  Empty audiences/zero campaign limits cannot yield an executable nonempty plan.
- **Integrator action:** Нурсултан imports the three exports from `strategy`,
  loads history, executes returned pilot requests and refreshes resources after
  each call. Official profile attribute is `env.customer_profile`, not the
  `env.profile` spelling in the contract introduction; no shared contract was
  edited. Ерлан runs independent checks and submission reproducibility after
  integration. Shared files and root agent.py were not changed.
