# Нурсултан — интеграция и сдача

Мы работаем от имени Нурсултана. Задача [T-03](../tasks/T-03.md),
ветка `feat/T-03-nursultan-agent`. Ресурс: личный Pro 20×.
Общий график и резерв: [PLAN.md](../../PLAN.md).

## Что делаем

1. Сверяем дедлайн платформы; готовим локальный официальный пакет без добавления
   данных в Git. Проверяем Python/pandas/numpy. Измеряем неизменённый template.
2. Создаём agent.py: публичный env → три функции strategy → пилоты → результат.
   Загрузка данных, ошибки, таймер, проверка лимитов и запись наблюдений — наша зона.
3. До готовности ядра не пишем его вместо Бауыржана и не меняем strategy/.
4. Получаем его первый опубликованный коммит сразу, независимо от готовности
   остальных документов. Fetch разрешён запросом пользователя; объединение
   веток — по отдельной команде оператора согласно AGENTS.md.
5. Подключаем ядро, передаём точный интеграционный hash Ерлану. Сверяем результаты,
   закрываем критические дефекты и фиксируем версию до 16:45.
6. Генерируем CSV, сверяем повторяемость, проверяем комплектность и сдаём
   по команде владельца с резервом до закрытия платформы.

Не принимаем улучшение только по одному удачному seed. История задаёт prior,
пилоты обновляют оценку; скрытые эффекты не доступны. Проверки безопасности
бюджета не поручаем LLM. Общий runtime целевой <5 минут.

## Модели

**GPT-6 Astra high** — решение трудных вопросов математики, архитектуры и итоговое
ревью чужого кода. **GPT-6 Sol medium** — интеграция, небольшие исправления и команды.
High включать для сложного дефекта; Max/Ultra не использовать по умолчанию.
Модель выбирать из реально доступных аккаунту; доступный Sol — запасной вариант.
Сохранить около 30% остатка ресурса на финальные ошибки; reset только по явному запросу.
