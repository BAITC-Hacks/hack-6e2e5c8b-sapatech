## Ресурсы и модели

У тебя два заявленных ресурса Pro 5×. Счётчики независимы; это не один общий 10×.
Используй доступные тебе разрешённые учётные записи без передачи ключей/паролей.
Основная сессия: **GPT-6 Sol, high** для формул и стратегии, **medium** для кода.
Вторая сессия при доступности: независимое чтение/ревью формул и крайних случаев,
без записи в те же файлы. Трудный математический спор передай Нурсултану на Astra high.
Если модели нет в списке аккаунта, используй доступный Sol (например GPT-5.6 Sol).
Не включай максимальное рассуждение для каждой правки. API-кредиты ядру не нужны.

## Порядок работы

1. Прочитай обязательный контекст. Проверь branch/status и свой Git author.
2. За первые 10 минут изучи колонки profile/tariffs/history и публичные фильтры.
3. За 45–60 минут выдай простые рабочие три функции и первый коммит. Даже простой
   portfolio нужен интегратору раньше идеальной оптимизации.
4. Затем улучшай diverse exploration, shrinkage/консервативные оценки,
   повторные пилоты там, где они способны изменить решение, и предельный net gain.
5. Передай hash, сигнатуры, команду проверки и ограничения. Продолжай улучшения
   маленькими коммитами; не удерживай рабочую версию до конца.

История содержит 14 823 перехода; ID истории не пересекаются с целевой аудиторией.
Она помогает построить prior, но не даёт вероятность согласия целевой аудитории.
Есть 1 407 строк с исходным ARPU <= 0: не дели на него. Проверяй пропуски сегментов.
Начни с current_tariff × arpu_segment, затем расширяй только при измеримой пользе.
Не фиксируй заранее победившие тарифы. Не применяй channel multiplier дважды к пилоту.
Платные каналы оценивай по дополнительному выигрышу за вычетом цены;
бесплатный push всё равно тратит контакты и может давать отрицательный эффект.

## Старт в Git

После появления пакета на origin, при чистом рабочем дереве:

```powershell
git fetch origin
git switch -c feat/T-04-bauyrzhan-strategy origin/docs/T-02-team-plan
git status --short --branch
```

Если ветка уже существует — переключись на неё, не пересоздавай и не делай reset.
Если remote-ветки ещё нет, первый коммит пока доступен только у Нурсултана.
Коммит результата: `feat(strategy): implement pilot-aware campaign core [T-04]`.
Публикация своей ветки — по команде владельца; main не менять.
