# Пятиминутная демонстрация Beeline

Сценарий для **интегрированного** `agent.py`. Не подменять результат команды
цифрами официального template. Перед показом записать hash проверенного
коммита и прогнать команды из README на отдельной копии пакета участника.

| Время | Что показать | Что сказать |
|---|---|---|
| 0:00–0:45 | Постановка и публичные `customer_profile`, тарифы, каналы | У нас синтетические 23 441 абонент; выбираем до 10 кампаний смены тарифа, максимизируя чистый прирост ARPU с учётом стоимости контакта. |
| 0:45–1:30 | `Agent.act(env)` и публичный вызов `run_pilot` | Агент использует только доступные профили и ответы пилотов. Скрытую модель эффекта он не видит. |
| 1:30–2:20 | Изменение решения при разных результатах пилотов | Показать два контролируемых прогона public stub. Называть только реально проверенные различия и нарушения контракта, если они есть. |
| 2:20–3:10 | Исходный список кампаний и raw-аудит | Показать тариф, канал и сегмент каждого предложения до sanitizer; проверить 1–10 кампаний, лимиты 5 000 на кампанию, 15 000 контактов и 100 000 бюджета вместе с пилотами. |
| 3:10–4:05 | Официальный `local_eval.py --runs 10` и сравнение на seed 0–9 | Показать среднее, медиану, минимум, разброс, затраты, время и число положительных прогонов. Назвать hash агента и стратегии. Не выбирать только удачный seed. |
| 4:05–4:35 | Два `make_submission.py` в независимой копии | Показать одинаковые SHA-256 и число строк в CSV, не открывая клиентские данные на экране. |
| 4:35–5:00 | Ограничения | Mock проверяет механику, но использует выдуманные эффекты; скрытый балл заранее неизвестен. Продемонстрировать, что ключи/API/GPU не нужны для базового локального запуска. |

## Команды перед демонстрацией

Выполнять из корня ветки T-05, подставив локальные пути. `compare_agents.py`
сам проверяет raw-ответ на каждом seed **до** официального sanitizer; ненулевой
код означает, что нужно показать и объяснить ошибки, а не скрыть JSON-вывод.

```text
python -m unittest evals.test_contract_checks -v
python evals/check_agent.py --agent <integrated-package>/agent.py --package <integrated-package> --seed 42
python evals/check_agent.py --agent <integrated-package>/agent.py --package <integrated-package> --feedback-check
python evals/compare_agents.py --baseline-agent <official-package>/agent_template.py --candidate-agent <integrated-package>/agent.py --package <integrated-package> --runs 10
python evals/check_submission.py --package <official-package> --agent <integrated-repo>/agent.py --strategy <integrated-repo>/strategy
```

Путь `<integrated-package>` обозначает **отдельную локальную копию**
официального пакета с `agent.py` и `strategy/` интегрированного коммита.
Оригинальный scorer и общий `submission.csv` не менять. Перед показом
сверить, что baseline в сравниваемой копии имеет те же данные и код
официального пакета.
