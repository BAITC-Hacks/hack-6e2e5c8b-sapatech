## Команды перед демонстрацией

Сначала выполнить чистый порядок установки из README. Из его нового клона
запустить команды ниже. `check_agent.py` проверяет raw-ответ **до** official
sanitizer; ненулевой код нельзя скрывать. Старый `compare_agents.py` не
использовать для сравнения двух командных ревизий: их общий импорт `strategy`
ещё не изолирован, независимый T-09 verdict не опубликован.

```sh
.venv/bin/python -m unittest scripts.test_agent strategy.tests.test_core evals.test_contract_checks -q
.venv/bin/python local_eval.py
.venv/bin/python evals/check_agent.py --agent agent.py --package . --feedback-check
.venv/bin/python make_submission.py
shasum -a 256 submission.csv
```

В официальном `local_eval.py` строка «Кампаний: 30» включает 20 пилотов и
10 финальных кампаний, а не нарушение лимита 10. На машине Ерлана указанные
команды прошли в одноразовом снимке macOS/Python 3.12.14 с exact numpy/pandas;
сведения о подлинном ZIP и 100 seed — из аудита T-07. Скриншоты/логи можно
показывать только без строк абонентской базы. Общий CSV не перезаписывать.
