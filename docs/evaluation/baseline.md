# Проверка официального шаблона Beeline

Дата: 2026-09-23. Это baseline официального `agent_template.py`, не результат
командного агента. Использован локально распакованный пакет участника. Данные и
сгенерированные CSV в Git не добавлялись.

## Что запускалось

```text
python -m unittest evals.test_contract_checks -v
python evals/check_agent.py --agent <package>/agent_template.py --package <package> --seed 42
python evals/check_agent.py --agent <package>/agent_template.py --package <package> --feedback-check
python evals/compare_agents.py --baseline-agent <package>/agent_template.py --candidate-agent <package>/agent_template.py --package <package> --runs 10
python evals/check_submission.py --package <package> --agent <package>/agent_template.py
```

`<package>` — локальная распакованная папка с официальными `local_eval.py`,
`make_submission.py` и CSV. Команды `evals/` запускаются из корня ветки T-05.
Установленные зависимости: Python, pandas, numpy. Сравнение baseline с ним же
проверяет, что runner применяет одинаковые seed и выдаёт одинаковые значения.

## Измеренные результаты

| Показатель | Официальный template, seed 0–9 |
|---|---:|
| Завершённых прогонов | 10/10 |
| Средний net ARPU | −480 836.18 |
| Медиана net ARPU | −357 947.80 |
| Минимум net ARPU | −1 019 431.06 |
| Максимум net ARPU | −76 493.45 |
| Разброс max − min | 942 937.61 |
| Положительных прогонов | 0/10 |
| Средние затраты на коммуникацию | 29 270.40 |
| Среднее число контактов | 7 317.6 |
| Пилотов | 6 в каждом прогоне |

После добавления raw-аудита в сравнительный runner обнаружено нарушение
контракта самого template на seed 3: `Agent.act` вернул `[]` вместо 1–10
финальных кампаний. Официальный evaluator всё равно выдал net-результат за
пилоты. Поэтому сравнение template с ним же печатает сводку, но возвращает
код 1 из-за `raw_error_runs=1` у каждой стороны. Это не ошибка команды.
Runner также отдельно замеряет время `Agent.act`: в этой машине около
0.02–0.03 секунды в среднем для template. Полный вызов evaluator занимает
около 0.1 секунды на seed и включает дополнительные операции. Это не
гарантия времени на другой машине.

При seed 42 исходный ответ шаблона содержал две корректные финальные кампании.
Он провёл 6 пилотов по 150 контактов: 900 пилотных контактов, 3 600 у.е.
Финал добавил 4 670 контактов и 18 680 у.е. Итого: 5 570 контактов,
22 280 у.е. Raw-валидатор ошибок не обнаружил.

Публичный stub с ответом `observed_lift_ratio=+0.5` изменил решение шаблона,
но две последние кампании обрезаются общим остатком контактов. При ответе
`-0.5` шаблон возвращает ноль финальных кампаний, что нарушает требование
1–10. Оба случая демонстрируют поведение шаблона; к коду команды эти выводы
не относятся. `--feedback-check` возвращает код 1, поскольку обнаруживает
контрактные ошибки в двух искусственных сценариях.

Два запуска официального `make_submission.py` на шаблоне в отдельной временной
копии дали одинаковый SHA-256 CSV:
`2111f50e6c8322d56609bd835257c89c371cb4a26eebbc61543294141f0e807b`
и по 2 кампании. Командный `submission.csv` ещё не проверялся.

## Ограничения интерпретации

Mock использует другую модель эффектов, чем скрытое судейство. Эти числа
показывают только поведение алгоритма и evaluator на предоставленной заглушке.
Сравнение с интегрированным агентом должно использовать те же seed 0–9,
отдельно проверить сырой ответ и повторную генерацию CSV. Результат нужно
добавить сюда после появления интегрированного коммита, указав его hash.
